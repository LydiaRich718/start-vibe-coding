First, three words

People will throw these at you. Here's all they mean.

🗂️

VS Code

A free app that holds your project's files. Think of it as a folder with superpowers. This is where you'll work.

✨

Claude Code

The AI that lives inside VS Code. You chat with it, and it creates and edits the files for you.

⌨️

Terminal

A plain text box where you type commands instead of clicking. You can mostly ignore it. It's optional here.

🧠 So what is "vibe coding"?

It's describing what you want in normal words and letting the AI write it. You stay the boss: you decide what it should do, you look at the result, and you say what's wrong. You are not expected to read or understand the code. You are expected to look at what came out.

0

Get a Claude account

≈ 5 minutes · you need this first

Claude Code is the AI assistant. To use it, you need a Claude account with a paid plan (the free plan doesn't include Claude Code).

  1. Go to claude.ai and click Sign up.
  2. Use your email or your Google account. Confirm the code they email you.
  3. Once you're in, click your name (bottom left) → Settings → Plans (or go to claude.com/pricing).
  4. Pick Pro. It's the normal starting plan and it includes Claude Code.
  5. Pay. Keep the email/password you used — you'll sign in with it again in Step 4.

💸 Which plan?

  • Free — chat only. Will not work for this guide.
  • Pro — around $20/month. Start here. Plenty for learning and small projects.
  • Max — for when you're coding all day and keep hitting limits. You can upgrade later in one click. Don't start here.

Prices change — check the pricing page for today's number.

⏳ "I ran out of usage"

Every plan has a limit that refills every few hours. If Claude says you've hit it, that's normal — take a break, or upgrade. You didn't break anything.

Install VS Code

≈ 5 minutes · free forever

This is the app your project lives in. It's free and made by Microsoft.

  1. Go to code.visualstudio.com/download.
  2. Click the big button for your computer. The site usually guesses correctly.
  3. Wait for the download to finish (bottom of your browser, or your Downloads folder).

🍎 Then, on Mac

  • Double-click the downloaded .zip file. A blue "Visual Studio Code" icon appears.
  • Drag that icon into your Applications folder. (Open Finder → Applications → drag it in.)
  • Double-click it to open. If a box says "downloaded from the internet, are you sure?" — click Open.

🪟 Then, on Windows

  • Double-click the downloaded .exe installer.
  • Accept the agreement, then click Next through every screen. The defaults are fine.
  • Tick "Add to PATH" if you see it — it's usually already ticked.
  • Click Install, then Finish. VS Code opens.

3

Make your first project folder

≈ 2 minutes

Everything you build lives in a folder. Claude only touches files inside the folder you open. That's your safety net.

  1. Open Finder (the smiley face in your dock).
  2. Click Documents in the left sidebar.
  3. Right-click in the empty space → New Folder.
  4. Name it first-try and press Return.
  1. Open File Explorer (the folder icon in your taskbar).
  2. Click Documents in the left sidebar.
  3. Right-click in the empty space → New → Folder.
  4. Name it first-try and press Enter.

Now open it in VS Code

  1. Switch back to VS Code.
  2. Top menu → File → Open Folder…
  3. Find Documents → click first-try once → click Open.
  4. If it asks "Do you trust the authors of the files in this folder?" click Yes, I trust the authors. (You made the folder. You trust you.)

👀 You should see

FIRST-TRY in the top-left panel, and nothing under it. An empty folder is exactly right. Don't panic.

💡 Naming rule for later

Folder names: lowercase, no spaces. Use dashes. my-recipe-site ✅   My Recipe Site ❌ — spaces cause weird errors down the line.

5

Send your first two messages

≈ 5 minutes · the fun bit

Message one tells Claude how to treat you. Message two gives it a job. Copy them exactly — you can be sloppier once you've got the hang of it.

Message 1 — paste this first
I am completely new to coding and to VS Code. Treat me like a total beginner. Use simple words and explain any technical term in one short line. Give me one step at a time and wait for me. Before making big changes, tell me your plan first and let me approve it.
Message 2 — then paste this
I want to make a very simple one-page website. Please make a heading, three colourful boxes, and a button that shows a friendly message when clicked. Keep it beginner-friendly and put it all in one file. When you are done, tell me exactly how to open it and look at it.

👀 You should see

  • Claude writes back explaining what it's about to do.
  • A file called index.html appears in the left panel. You made a file! Sort of!
  • Claude may pause and ask permission to create or edit something.

🚦 About those permission pop-ups

Claude asks before it changes things on your computer. Read the one-line description, and if it's creating or editing a file inside your first-try folder — say yes. That's the whole job.

Say no (or just ask "why do you need that?") if it wants to delete a lot of things, touch folders outside your project, or install something you didn't ask about. You're allowed to ask questions before approving.

🧭 The one rule that saves you

Change one thing at a time, then look. If you ask for eight changes at once and something breaks, you have no idea which one did it. Small steps are faster than big ones. Always.

🗺️ For anything bigger than a tweak

Say: "Before you change anything, tell me your plan." Read it. If it sounds wrong, say so. If it sounds right, say "go ahead." This takes 20 seconds and prevents most disasters.

8

Save points & not getting burned

≈ 5 minutes · do not skip

🎮 Save points (this is what "Git" is)

Git is a save-point system, like in a video game. Every time something works, you make a save point. If you later wreck it, you load the last save. Claude sets it all up — you just say the words:

Say this when something works
This version works. Please set up Git if it isn't already, and commit this as a save point.
Say this when you've broken it
Something is broken. Please take me back to the last working save point, and explain in simple words what went wrong.

Make a save point before anything big, and after anything that works.

🔒 Never paste these into a chat

  • Passwords.
  • API keys or secret tokens (long random strings — you'll know them when you see them).
  • Database passwords or connection strings.
  • Real customer names, emails, card numbers, or medical info.

If a project genuinely needs a key, ask Claude: "Set this up using an environment variable so the key isn't in the code." It'll know what to do.

🛑 If Claude goes off the rails

Stop it (there's a stop button while it's working). Then say, in order:

  • "Stop. Don't change anything else."
  • "Explain what you just changed, in simple words."
  • "Undo that." — or go back to your last save point.

You will not hurt Claude's feelings, and you cannot break your computer from this chat box.

🌟 The four things to remember

  • You don't have to understand the code. You do have to look at the result.
  • Ask questions the second you're confused. There are no stupid ones here.
  • Keep every change small.
  • Make a save point whenever something works.

When you get stuck

You will get stuck. Everyone does, forever. Here's the usual suspects.

I can't find the Claude icon in VS Code

Quit VS Code completely (not just close the window — ⌘+Qclose it from the taskbar) and open it again. If it's still missing, go back to the Extensions panel and check Claude Code says Installed, published by Anthropic.

It says I need to sign in, or that my plan doesn't work

Claude Code needs a paid plan (Pro or higher). Check at claude.ai → Settings → Billing that your subscription is active, then sign out and back in inside VS Code.

Claude is asking permission for something. Do I say yes?

Yes if it's creating or editing a file inside the folder you're working in — that's the job you gave it.

Ask first if it wants to delete lots of files, work outside your project folder, install software, or send something to the internet. Type "why do you need that?" — it'll explain, and nothing happens until you approve.

I don't see my change in the browser

Refresh the page (⌘+RCtrl+R). Still nothing? You might be looking at an old copy of the file — ask Claude: "Which exact file should I open, and what's its full path?"

Everything broke and I don't know what happened

Say: "Stop. Explain what changed in simple words, then undo it." If you made a save point, say: "Take me back to the last commit." This is exactly why save points exist. Nothing is ever really lost.

There's scary red text everywhere

Red text is normal. It's usually a warning, not a disaster. Copy the whole red bit, paste it to Claude and say: "I got this error. What does it mean and how do I fix it?" That's what professionals do too.

It says I've hit my usage limit

Every plan refills its allowance every few hours. Wait it out, or upgrade your plan. Nothing is broken and your work is saved.

Do I need Node.js? Python? Git? Homebrew?

Not to start. The VS Code extension is enough. When a project genuinely needs one of those, Claude will say so and can walk you through installing it. Don't install things "just in case".

Optional: the terminal / command-line version

You can skip this forever. But if you want Claude Code as a command in a terminal window: in VS Code go to Terminal → New Terminal, paste the line for your computer, press Enter, then type claude to start it.
