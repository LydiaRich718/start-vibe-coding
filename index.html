0

Get a Claude account

≈ 5 min · paid · needed first

Claude Code needs a paid Claude plan. The free plan won't work.

  1. Go to claude.ai → Sign up. Use email or Google.
  2. Once in: click your name (bottom left) → Settings → Plans.
  3. Pick Pro (about $20/month). It includes Claude Code.
  4. Remember the login — you'll need it in Step 6.

💸 Which plan?

  • Free — chat only. Won't work here.
  • Pro — start here. Plenty for learning.
  • Max — only if you're coding all day and hitting limits. Upgrade later in one click.
1

Get a GitHub account

≈ 3 min · free

GitHub stores your projects online, free. You need it later to put things on the internet. Do it now while you're in signing-up mode.

  1. Go to github.com/signup.
  2. Enter your email, make a password, pick a username.
  3. Your username shows up in links — pick something you'd say out loud. Lowercase, no spaces.
  4. Confirm the code they email you. Choose the Free plan.

💡 Write down your username

You'll need it, and it's easy to forget which one you picked. Free covers everything in this guide — there's nothing to pay for.

2

Get a Vercel account

≈ 2 min · free

Vercel puts your project on the real internet, with a real link you can text someone. Also free.

  1. Go to vercel.com/signup.
  2. Choose Hobby — that's the free one.
  3. Click Continue with GitHub and log in with the account you just made.
  4. Approve the permissions box. Done — nothing to set up yet.

👀 You should see

An empty Vercel dashboard saying you have no projects. Correct. Close the tab; you'll come back at Step 9.

3

Install VS Code

≈ 5 min · free
  1. Go to code.visualstudio.com/download.
  2. Click the button for your computer. The site usually guesses right.

🍎 On Mac

  • Double-click the downloaded .zip. A blue icon appears.
  • Drag it into your Applications folder, then double-click to open.
  • "Downloaded from the internet, are you sure?" → Open.

🪟 On Windows

  • Double-click the downloaded .exe.
  • Accept the agreement, then Next through every screen — defaults are fine.
  • Install → Finish. VS Code opens.

Make your first project folder

≈ 2 min

Everything lives in a folder. Claude only touches files inside the folder you open — that's your safety net.

  1. Open Finder → Documents.
  2. Right-click empty space → New Folder. Name it first-try.
  1. Open File Explorer → Documents.
  2. Right-click empty space → New → Folder. Name it first-try.

Open it in VS Code

  1. Top menu → File → Open Folder…
  2. Pick first-try → Open.
  3. "Do you trust the authors?" → Yes, I trust the authors. You made the folder. You trust you.

👀 You should see

FIRST-TRY top-left, with nothing under it. An empty folder is exactly right.

💡 Naming rule

Lowercase, no spaces, use dashes. my-recipe-site ✅   My Recipe Site ❌ — spaces cause weird errors later.

One sets the ground rules. Two gives it a job. Click to copy.

🚦 Those permission pop-ups

Yes if it's creating or editing a file inside first-try — that's the job you gave it. Ask first if it wants to delete lots of things, work outside your folder, or install something. Typing "why do you need that?" is always allowed.

🧭 The one rule that saves you

Change one thing, then look. Ask for eight changes at once and something breaks — you'll have no idea which one did it. For anything bigger than a tweak, say "tell me your plan first."

9

Save your work & put it online

≈ 10 min · this is where the accounts pay off

📌 What Git actually is

Git is an undo history for your whole project. Each time you commit, it records exactly what every file looked like at that moment. Later you can go back to any of those moments. GitHub is just a website that stores that history online, so it's backed up and shareable.

You don't have to learn any of it. Claude does the work — you say the words:

When something works
This version works. Please set up Git if it isn't already, and commit this as a save point.
When you've broken it
Something is broken. Take me back to the last commit, and explain in simple words what went wrong.

Commit before anything big, and after anything that works.

🌍 Now get a real link

Time to use those free GitHub and Vercel accounts. Paste this:

Paste into Claude
I want to put this on the internet so I can send someone a link. I have free GitHub and Vercel accounts. Please walk me through it one step at a time, using the free options, and tell me exactly what to click. Stop and wait after each step.

👀 What happens

  • Claude pushes your project to GitHub (it may ask you to log in once).
  • You connect that GitHub project to Vercel in the browser.
  • Vercel hands you a link ending in .vercel.app.
  • Text it to someone. It's live on the actual internet.

♻️ From now on

Every time you commit and push, Vercel updates your live site automatically. Just say "commit and push this" and refresh the link a minute later.

Three rules that keep you safe

🔒 1. Never paste these into a chat

Passwords · API keys and secret tokens (long random strings) · database passwords · real customer names, emails or card numbers. If a project genuinely needs a key, say: "Set this up as an environment variable so the key isn't in the code."

🛑 2. If it goes off the rails, say these in order

"Stop. Don't change anything else." → "Explain what you just changed, in simple words." → "Undo that." You won't hurt its feelings, and you can't break your computer from a chat box.

🐢 3. Small changes beat big ones

One change, look, commit. Every time. It feels slower and it is dramatically faster.

When you get stuck

You will. Everyone does, forever. The usual suspects:

I can't find the Claude icon

Quit VS Code completely (⌘+Q) and reopen. If it's still missing, check the Extensions panel says Claude Code is Installed, by Anthropic.

It says I need to sign in, or my plan won't work

Claude Code needs a paid plan. Check claude.ai → Settings → Billing, then sign out and back in inside VS Code.

Should I approve this permission pop-up?

Yes for creating or editing files in your project folder. Ask first for deleting lots of files, working outside the folder, installing software, or sending things to the internet. Nothing happens until you approve.

My change isn't showing up

Refresh the browser (⌘+R)(Ctrl+R). Still nothing? Ask: "Which exact file should I open, and what's its full path?"

Everything broke

Say: "Stop. Explain what changed in simple words, then undo it." If you committed, say "take me back to the last commit." This is exactly why commits exist.

There's scary red text

Red is normal — usually a warning, not a disaster. Copy the whole thing, paste it to Claude, and say: "I got this error. What does it mean and how do I fix it?" That's what professionals do too.

I hit my usage limit

Every plan refills every few hours. Wait, or upgrade. Nothing is broken and your work is saved.

My site didn't update after I pushed

Give Vercel a minute, then hard-refresh. If it's still old, check on vercel.com/dashboard whether the latest deploy succeeded — and if it failed, paste the error to Claude.

Do I need Node.js? Python? Homebrew?

Not to start. Claude will say so when a project genuinely needs one. Don't install things "just in case".
